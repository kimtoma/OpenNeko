# High-resolution sprite revision — 2026-09-06

This report records the earlier 256px revision. It has been superseded by the
[selected 1024px pixel house-cat set](SPRITES-PIXEL-1024-2026-09-06.md).

All five built-in cats in this revision use **256×256 RGBA frames displayed at 128 points**.
The redraw keeps larger facial features, rounded proportions, and soft outlined
edges. Frames are sampled directly from the generated source sheets; there is no
64px intermediate, forced pixel grid, or enlargement of a reduced image.

The app includes 280 character frames (five skins × 14 states × four frames),
four punch frames, and six geometry metadata files. All 108 homepage sprite PNGs
match their corresponding app assets byte for byte. The previous artwork is
preserved in `output/sprite-backups/20260906-cute-outline/`.

## Artwork and edge handling

The 21 selected source sheets were created using built-in `image_gen` and saved
under `assets/gen/cute-outline-20260906/`. Generation prompts and source records:

- [Default, black, and calico](../assets/gen/cute-outline-20260906/prompts-root.json)
- [Orange](../assets/gen/cute-outline-20260906/orange-provenance.json)
- [Pink](../assets/gen/cute-outline-20260906/pink-provenance.json)
- [Punch sequence](../assets/gen/cute-outline-20260906/effects-punch-provenance.json)

The [Swift import workflow](../scripts/SPRITE_PRODUCTION.md) extracts frames using
transparent gutters, aligns each loop with a shared scale, and samples premultiplied
RGBA to preserve soft edges. All 284 frames are downsampled from the source cells:
scale factors range from 0.48815 to 0.97630, with **zero upscaled frames**.

Opaque source backgrounds use conservative exterior isolation followed by a
bounded two-source-pixel fringe cleanup. Bright interior pixels remain protected:
all 21 source reports verify **zero protected-white loss**. Native-alpha sources
retain their soft alpha. Transparent output pixels contain zero hidden RGB, and
all frames have at least 24px of padding. Eight secondary alpha-1 pixels remain
in six frames; these have a combined equivalent opaque area of 0.0314 pixels.
Different skins retain small silhouette differences from their source drawings.

`CatScene` preserves the 256px backing image at a 128pt display size and uses linear
filtering for these assets. Geometry metadata keeps feet grounded and drag anchors
aligned. Landing recovery resets scale before restoring texture size, preventing
overlapping walk and landing actions from changing the cat's resting size.
Settings previews and the homepage also use smooth image sampling.
